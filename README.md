# 🎵 Arduino Buzzer Turkish Songs

Bu depo, popüler Türk şarkılarının ve dizi müziklerinin **Arduino Buzzer** ile çalınabilmesi için hazırlanmış C++ / Arduino ino kodlarını içerir. 

Projede yer alan tüm kodlar, standart bir buzzer ile doğrudan çalışacak ve kolayca Arduino IDE'ye kopyalanabilecek şekilde optimize edilmiştir.

---

## 🛠️ Donanım Bağlantısı

Kodların çalışabilmesi için buzzer bağlantılarını aşağıdaki şemaya göre yapmanız yeterlidir:

| Buzzer Pini | Arduino Pini |
| :--- | :--- |
| **Artı (+)** | **Digital Pin 8 (D8)**[cite: 3] |
| **Eksi (-)** | **GND**[cite: 3] |

## 📂 İçerik / Şarkı Listesi

Depo içerisinde yer alan popüler eserler ve melodiler:

1. **Succession (Ana Tema - Piyano)**[cite: 1]
   * Nicholas Britell'in popüler dizi müziğinin buzzer uyarlaması[cite: 1].
2. **Kum Gibi (Ahmet Kaya)**[cite: 3]
   * Hem standart piyano notaları hem de melodika versiyonuna (*Lab*, *Mib*, *Do\** geçişleri ile) uygun olarak uyarlanmış versiyonları[cite: 3, 5].

---

## 🚀 Kullanım Rehberi

1. Depodaki `.ino` uzantılı dosyalardan birini seçin veya kodu kopyalayın.
2. **Arduino IDE** programını bilgisayarınızda açın.
3. Kodu yeni bir projeye yapıştırın.
4. Arduino kartınızı (örn. Uno, Nano vb.) bilgisayarınıza bağlayın.
5. Doğru kartı ve portu seçtikten sonra **Yükle (Upload)** butonuna tıklayın.
